YIELDSCOPE — country building photos (optional)
================================================

By default each country shows its real flag.

To show a real BUILDING / landmark photo instead, just drop a photo
into this folder named with the country's 2-letter code (lowercase),
ending in .jpg. The site picks it up automatically — no code changes.

Filenames to use:
  pk.jpg  -> Pakistan      (e.g. Minar-e-Pakistan, Faisal Mosque)
  in.jpg  -> India         (e.g. Taj Mahal, India Gate)
  bd.jpg  -> Bangladesh    (e.g. Jatiyo Sangsad, Sriti Shoudho)
  ng.jpg  -> Nigeria       (e.g. Abuja National Mosque, Zuma Rock)
  eg.jpg  -> Egypt         (e.g. Pyramids of Giza)
  tr.jpg  -> Türkiye       (e.g. Blue Mosque, Hagia Sophia)
  ar.jpg  -> Argentina     (e.g. Obelisco de Buenos Aires)
  za.jpg  -> South Africa  (e.g. Table Mountain)
  us.jpg  -> United States (e.g. Statue of Liberty)

For a consistent look, use photos that are:
  - landscape, roughly 3:2 (e.g. 1200 x 800 px)
  - similar brightness

The site already crops them all to the same size and adds the same
violet tint, so they stay uniform automatically.

Tip: you can also just send the photos in chat and I'll add them for you.
